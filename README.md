# 📝 ROXIE Not Defteri

Basit ve kullanışlı bir terminal tabanlı not defteri uygulaması.

Bu proje, Python öğrenme sürecimde geliştirdiğim ilk terminal uygulamalarından birisi. Amaç; dosya işlemlerini, fonksiyonları ve `os` modülünü kullanmayı öğrenmekti.

   ✨ Özellikler

- 📝 Yeni not oluşturma
- 📖 Not okuma
- 📋 Kayıtlı notları listeleme
- 🗑️ Not silme
- ✏️ Not ismini değiştirme
- ⭐ Favorilere not ekleme
- ❌ Favorilerden not çıkartma

## 📁 Proje Yapısı

```
ROXIE-Not-Defteri/
├── main.py
├── favoriler.txt
├── Notlar/
│   ├── kek_tarifi
│   ├── yapılacaklar
│   └── alışveriş
└── README.md
```

> **Not:** `Notlar/` klasöründe uygulamayı denemeniz için **3 adet örnek not** bulunmaktadır.

## 🚀 Nasıl Kullanılır?

1. Projeyi indirin veya klonlayın.
2. Python 3 yüklü olduğundan emin olun.
3. Terminalden aşağıdaki komutu çalıştırın:

```bash
python main.py
```

## 📚 Bu Projede Kullandığım Konular

- Fonksiyonlar (`def`)
- `return`
- `while` döngüsü
- `try` / `except`
- Dosya okuma ve yazma
- `os` modülü
- Dosya oluşturma, silme, listeleme ve yeniden adlandırma
